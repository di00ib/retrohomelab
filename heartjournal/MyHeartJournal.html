☁️ Cloud Sync and Backup

Your readings are always saved locally in this browser. Use the options below to sync across all your devices. You can use all three at once - FIREBAT is primary, Supabase is fallback, Google Drive is for file backups.

🖥️ FIREBAT Homelab (Primary - Your Own Server)
Saves data to your FIREBAT server over Tailscale. Most private option - your data never leaves your own hardware. Requires the heartjournal-api Docker container on FIREBAT (ask Claude to help set it up - takes about 5 minutes).
Not configured
🗄️ Supabase (Free Cloud Database - Fallback)
Free cloud database that syncs across all devices in real time. Good fallback when FIREBAT is unreachable. Requires a free account at supabase.com. Data is encrypted in transit and at rest.
Not configured
📁 Google Drive / OneDrive / Dropbox (File Backup)
Download your data as a JSON backup file and upload it to any cloud storage. Load it back on any device. Best for weekly backups or before doctor visits. Works everywhere with zero setup.
After downloading, drag the .json file into Google Drive, OneDrive, or Dropbox. On another device, download it and use Load from Backup File.

Once installed, it opens like a real app with no browser bar and works offline.
