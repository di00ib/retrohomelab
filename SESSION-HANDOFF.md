## DOCKER LESSONS LEARNED

### Network lesson
  New containers needing nginx proxy MUST join homelab_homelab network.
  Add to docker-compose.yml:
    networks:
      homelab_homelab:
        external: true
  And under the service:
    networks:
      - homelab_homelab

### DNS lesson
  Containers can't reach internet by default (pip install fails).
  Fix: add to docker-compose.yml under the service:
    dns:
      - 1.1.1.1
      - 1.0.0.1
  Prefer Cloudflare (1.1.1.1) over Google (8.8.8.8).
  Future: switch to 192.168.4.25 (Pi-hole) once Pi-hole fixed,
  with 1.1.1.1 as fallback.
