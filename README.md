## Projects

### ❤️ My Heart Journal
**[heartjournal.retrohomelab.dev](https://heartjournal.retrohomelab.dev)**

A free, private blood pressure tracker that works on any device.

- No account required to use
- Works offline once loaded
- OCR scanning of BP monitor photos
- PDF, CSV, and TXT report export for doctor visits
- Daily reminders with mute/unmute
- Optional free cloud sync via Supabase
- Installable as a PWA on iPhone, Android, and Windows

[Open App →](https://heartjournal.retrohomelab.dev) | [View Source](./heartjournal/)

## About This Repo

This repository hosts the public-facing projects from my personal homelab (RETRO HOMELAB).

The homelab itself runs on a MINISFORUM Mini PC with Ubuntu Server, Docker, Tailscale, and 19 self-hosted services. These public projects are the outward-facing pieces — free tools anyone can use, built and maintained as a hobby.

**Stack:** HTML · CSS · JavaScript · Python · Docker · Tailscale · Cloudflare · GitHub Pages

---

## Privacy

All apps in this repo are designed with privacy first:
- No tracking or analytics
- No data collection by this repo or its author
- User data stays on the user's device or their own chosen cloud account
